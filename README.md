# Prime Launcher v0.4.0 — أول لانشر عربي لماينكرافت

لانشر ماينكرافت (جافا) لويندوز، مبني بـ Electron (JavaScript). واجهة عصرية بالعربية والإنجليزية.

## التشغيل
```
npm install
npm start
```
(يتطلب Node.js 20+)

## بناء ملف التثبيت .exe
محلياً على ويندوز: `npm run dist` ← تجد `PrimeLauncher-Setup-0.4.0.exe` و `PrimeLauncher-Portable-0.4.0.exe` داخل `dist/`.

### البناء من GitHub مباشرة
1. ارفع هذا المجلد كمستودع على GitHub (فرع `main`).
2. تبويب **Actions** ← *Build Prime Launcher (Windows)* ← **Run workflow**، أو ادفع أي push.
3. تجد الملفات في **Artifacts**.
4. لإصدار رسمي: `git tag v0.4.0 && git push origin v0.4.0` ← يُنشأ **Release** تلقائياً وفيه ملفات الـ exe.

## ما تحتاجه لتفعيل بعض الميزات
- **تسجيل الدخول بمايكروسوفت**: سجّل تطبيقاً مجانياً في Azure (Entra ID) من نوع *Personal Microsoft accounts*، فعّل *Allow public client flows*، وانسخ **Application (client) ID** في الإعدادات ← الحسابات. ولاستخدام خدمات ماينكرافت يجب طلب موافقة Mojang على تطبيقك: https://aka.ms/AppRegInfo
- **CurseForge**: احصل على مفتاح API مجاني من https://console.curseforge.com وضعه في الإعدادات. (Modrinth يعمل بدون مفتاح.)
- **Java**: يُنزَّل تلقائياً (Adoptium) حسب إصدار ماينكرافت، أو حدّد مساراً خاصاً.

## مفتاح CurseForge المدمج (سري)
- يوجد `core/secrets.json` (محظور في `.gitignore`) فيه مفتاح CurseForge، فيعمل البحث مباشرة دون أن يراه المستخدم في الواجهة.
- **لا ترفع `core/secrets.json` إلى GitHub.** للبناء على GitHub: Settings ← Secrets and variables ← Actions ← New secret باسم `CF_API_KEY` وقيمته مفتاحك؛ الـ workflow يولّد الملف تلقائياً وقت البناء.
- تنبيه: أي مفتاح داخل تطبيق مثبّت يمكن استخراجه من يملك الخبرة. الحل الأمن 100% سيرفر وسيط (مثل Cloudflare Worker) يحمل المفتاح.
- المستخدم يقدر يضع مفتاحه الخاص في الإعدادات وهو يُفضَّل على المدمج.

## سكنات الأوفلاين
شرح إنشاء سيرفر سكنات: `docs/OFFLINE-SKINS.md`.

## الميزات
شاشة ترحيب أول تشغيل، حساب أوفلاين أو مايكروسوفت، نسخ (Instances) بإصدار واسم وصورة وذاكرة وجافا ودقة خاصة، Vanilla / Fabric / Quilt / Forge / NeoForge، تنزيل مودات وريسورس باك وشيدرز ومودباك من Modrinth و CurseForge (مع تثبيت الاعتماديات في Modrinth)، تفعيل/تعطيل/حذف المودات، العوالم ولقطات الشاشة، إصلاح النسخة، فتح مجلدها، الأخبار والإصدارات من خوادم Mojang، سكنات (رفع مباشر لحساب مايكروسوفت)، سمات: حسب النظام / حسب الوقت / أبيض / داكن / أسود OLED، و8 ألوان تمييز، وأنيميشن.

## حدود معروفة
- ويندوز فقط (x64). Realms غير مدعومة.
- سكنات الحسابات الأوفلاين تُحفظ للمعاينة فقط (ماينكرافت لا يعرضها بدون خادم/مود خاص).
- مودباكات CurseForge التي يمنع مؤلفوها التحميل الخارجي تُسرد ويُطلب تحميلها يدوياً.
- Forge/NeoForge يُثبَّتان عبر مثبّتهما الرسمي (قد يستغرق دقائق أول مرة).

## واجهة 0.4.0 الجديدة
- **شريط جانبي أيقوني** يعرض نسخك كأيقونات (اضغط للفتح، ＋ لنسخة جديدة) مع نقطة تشغيل للنسخة الجارية.
- **واجهة زجاجية** شفافة مع خلفية قابلة للتخصيص (صور Prime / بدون / صورتك) وتحكم بقوة التمويه.
- **لوحة الأوامر** بالضغط على `Ctrl + K`: تنقّل وتشغيل النسخ وتبديل الثيم واللغة من لوحة المفاتيح.
- **إعدادات الواجهة والخط**: لون رئيسي مخصص، حجم الخط، تدوير الزوايا، وCSS مخصص للمتقدمين.
- **الخط العربي Tajawal**: يُجلب تلقائياً أثناء البناء على GitHub (ترخيص OFL) إلى `renderer/assets/fonts`. للاستخدام المحلي انسخ ملفات `tajawal-{arabic,latin}-{400,500,700}-normal.woff2` إلى هذا المجلد، وبدونها يُستخدم خط النظام.
- تصميم الواجهة مستوحى من أسلوب لانشرات المصدر المفتوح الحديثة مثل [X Minecraft Launcher](https://github.com/Voxelum/x-minecraft-launcher) (MIT)؛ الكود مكتوب من جديد لـ Prime ولا يتضمن أي شعار أو ملفات منه.

## مركز المساعدة وأدوات التشخيص (0.3.9)
- صفحة **مركز المساعدة** في القائمة الجانبية: أجوبة ثنائية اللغة مع بحث وتصنيفات (البداية، الحسابات، جافا، المودات، السيرفرات، حل المشاكل، أسئلة شائعة).
- **أدوات التشخيص**: نسخ تقرير النظام (بلا رموز دخول) وفتح سجل اللانشر `launcher.log` ومجلد البيانات.
- زر **📜 السجل** يحتفظ بآخر تشغيل على القرص ويدعم **نسخ**.
- خيارات لكل نسخة: **ظهور اللانشر عند التشغيل** (تصغير / إبقاء / حسب الإعدادات) و**وضع Demo**.
- تحذير تلقائي إذا كان مسار البيانات يحتوي أحرفاً غير إنجليزية، مع شرح الحل.
- وسيط تشغيل `--workDir "D:\Games\Prime"` لنقل كل بيانات اللانشر إلى مجلد آخر (مسار كامل فقط).
