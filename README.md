## 🌟 نظرة عامة
**Prime Launcher** هو لانشر ماين كرافت مصمم خصيصاً للمجتمع العربي، يقدم تجربة تشغيل حديثة وسريعة مع دعم واسع للمشغلات والملحقات وإمكانية التخصيص الشامل.

---

## ✨ المميزات التفصيلية
* **👋 واجهة ترحيب أول تشغيل:** شاشة بداية وتثبيت إرشادية للمستخدم عند فتح التطبيق لأول مرة.
* **🔐 إدارة الحسابات:** دعم الحسابات الأوفلاين (Offline) أو حسابات مايكروسوفت (Microsoft).
* **⚙️ إدارة النسخ (Instances):** تخصيص كامل للنسخة يشمل الإصدار، الاسم، الصورة، حجم الذاكرة (RAM)، مسار Java، ودقة الشاشة الخاصة.
* **🚀 دعم شامل للمشغلات:** يدعم مشغلات Vanilla / Fabric / Quilt / Forge / NeoForge.
* **📦 تحميل الملحقات وإدارتها:** تنزيل المودات، حزم الموارد (Resource Packs)، الشيدرات (Shaders)، والمودباكات (Modpacks) مباشرة من **Modrinth** و **CurseForge** (مع تثبيت الاعتماديات تلقائياً في Modrinth).
* **🛠️ إدارة المودات والعوالم:** إمكانية تفعيل/تعطيل/حذف المودات بسهولة، استعراض العوالم، ولقطات الشاشة، مع خيار لإصلاح النسخة أو فتح مجلدها المباشر.
* **📰 الأخبار والإصدارات:** جلب آخر أخبار وإصدارات ماين كرافت مباشرة من خوادم Mojang الرسمية.
* **👕 السكنات (Skins):** إمكانية رفع السكن المباشر لحساب مايكروسوفت الخاص بك.
* **🎨 السمات والأنيميشن:**
  * سمات متعددة (حسب النظام / حسب الوقت / أبيض / داكن / أسود OLED).
  * 8 ألوان تمييز (Accent Colors) مختلفة.
  * أنيميشن وسلاسة في الواجهة.

## ⚙️ متطلبات تفعيل بعض الميزات

* **🔐 تسجيل الدخول بمايكروسوفت:**
  1. سجّل تطبيقاً مجانياً في Azure (Entra ID) من نوع **Personal Microsoft accounts**.
  2. فعّل خيار **Allow public client flows**.
  3. انسخ الـ **Application (client) ID** وضعه في **الإعدادات ← الحسابات**.
  4. لاستخدام خدمات ماين كرافت يجب طلب موافقة Mojang على تطبيقك عبر: [https://aka.ms/AppRegInfo](https://aka.ms/AppRegInfo)
* **🔌 CurseForge:** احصل على مفتاح API مجاني من [CurseForge Console](https://console.curseforge.com) وضعه في الإعدادات. *(ملاحظة: Modrinth يعمل مباشرة بدون الحاجة لمفتاح).*
* **☕ Java:** يُنزَّل تلقائياً (Adoptium) حسب إصدار ماين كرافت المناسب، أو يمكنك تحديد مسار خاص يدوياً.

## ⚠️ الحدود المعروفة (Known Limitations)

* **نظام التشغيل:** يدعم نظام ويندوز فقط (x64).
* **Realms:** غير مدعومة حالياً.
* **سكنات الحسابات الأوفلاين:** تُحفظ للمعاينة داخل اللانشر فقط (لأن ماين كرافت لا تعرضها بدون خادم أو مود خاص).
* **مودباكات CurseForge:** المودباكات التي يمنع مؤلفوها التحميل الخارجي تُسرد داخل اللانشر ويُطلب تحميلها يدوياً.
* **Forge / NeoForge:** يُثبَّتان عبر المثبّت الرسمي الخاص بهما (قد يستغرق تثبيتهما بضع دقائق عند أول تشغيل).
